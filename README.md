# JuzeppeOS Package Repository

Готовый статический сайт и HTTP-репозиторий для JuzeppeOS 0.9.1. Содержимое можно разместить на GitHub Pages или в любом каталоге Nginx; серверный код не требуется.

## GitHub Pages

1. Создайте публичный репозиторий GitHub, например juzeppe-repo.
2. Загрузите содержимое этого каталога в корень ветки main, включая .nojekyll и CNAME.
3. Откройте Settings → Pages → Build and deployment, выберите Deploy from a branch, main, / (root), сохраните.
4. В Settings → Pages → Custom domain укажите repo.juzeppe.icu. После сохранения у DNS-провайдера создайте запись CNAME:

       repo    CNAME    ВАШ-ЛОГИН.github.io.

   Если для repo уже существуют A/AAAA записи, удалите только конфликтующие записи именно этого поддомена. Остальные поддомены менять не нужно.
5. После проверки DNS включите Enforce HTTPS.

Официальное руководство:
https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site

## Подключение JuzeppeOS

В JuzeppeOS 0.9.1 репозиторий уже настроен установщиком. Открой магазин приложений или введи в терминале:

    jpkg refresh
    jpkg install office

Для JuzeppeOS 0.6.3 и старше сначала подключи репозиторий:

    jpkg repo https://raw.githubusercontent.com/gosuparenek/juzeppe-repo/main
    jpkg refresh

В качестве альтернативы укажите URL Pages вида https://ВАШ-ЛОГИН.github.io/juzeppe-repo без завершающего /, пока свой домен ещё не настроен.

## Новые приложения

1. Поместите файл .juz в packages/.
2. Запустите из корня репозитория:

       python rebuild-catalog.py

3. Загрузите обновлённый index.json и новый пакет на GitHub.

Сайт автоматически читает index.json. Тот же файл читают игровые компьютеры. При изменении версии пакета необходимо обновить его manifest.version, пересобрать индекс и опубликовать оба файла.

Загрузчик ОС находится в downloads/juzeppe.lua. При новой версии обновите этот файл и номер версии в index.html.

Встроенный каталог JuzeppeOS можно вернуть командой jpkg repo local.

## Stock / беспроводной склад

В JuzeppeOS 0.9.1 приложение Stock 1.1.0 читает Create Stock Ticker локально, через проводной модем или через беспроводной компьютер-посредник. Для склада нужен Create 6.0.7+ с интеграцией CC: Tweaked.

1. На компьютере рядом с тикером установите Wireless Modem либо Ender Modem. Тикер должен быть связан с нужной сетью Create.
2. В CraftOS скачайте и запустите службу:

       wget https://raw.githubusercontent.com/gosuparenek/juzeppe-repo/main/downloads/stock-host.lua stock-host.lua
       stock-host

3. Запомните Server ID. Оставьте программу запущенной, а чанк склада — загруженным.
4. На втором компьютере с беспроводным модемом установите или обновите Stock через Apps. При первом запуске разрешите stock.read и stock.remote. Нажмите Link, введите Server ID, затем Sync для повторного запроса. Пустое поле Link возвращает локальный режим; Src выбирает следующий локальный тикер.

Служба передаёт только список предметов и количества. Она не оформляет заказы. В текущем протоколе ID используется для выбора компьютера, а не для аутентификации: список предназначен для общедоступного просмотра в пределах сети Minecraft. Поддерживаются до 4096 записей за один запрос. Если связь пропала, Stock сохраняет старый список и показывает ошибку.

## Juzeppe Bridge (experimental)

Для открытия оригинального интерфейса Create из Stock установите серверный мод Juzeppe Bridge. Инструкция и исходники находятся в [bridge/README.md](bridge/README.md). В Stock 1.2.0 нажмите GUI после выдачи разрешения stock.native. Мод не нужен для обычного просмотра остатков.

## What'sJuz 1.0.0

Установите What'sJuz через Apps на JuzeppeOS 0.9.1. На каждом компьютере нужен один Wired, Wireless или Ender Modem. Для звука поставьте Speaker, а для речи — прилегающий к компьютеру блок Microphone из CC-Simple Voice Microphone integration (NeoForge 1.21.1, 1.0.0), установленного вместе с Simple Voice Chat и CC:T на сервере и клиентах.

Откройте приложение, разрешите phone.calls. Номер 10–99 случайно выдаётся каждому терминалу, сохраняется при перезапуске. Конфликты номеров разрешаются автоматически при встрече доступных телефонов. Откройте Dial и введите номер или выберите контакт; на другом телефоне нажмите Accept. Talk включает микрофон в принятом звонке, Mute выключает его, End завершает разговор. Speaker проигрывает звонок и гудки. Служба остаётся активной при закрытии окна, пока включена ОС. Off отключает службу и её модемный канал. On включает её обратно.

Речь передаётся в DFPWM с ограниченным буфером и только при принятом звонке с включённым микрофоном. Микрофонный блок слышит голоса игроков около него, поэтому используйте его в переговорной и предупреждайте присутствующих. Перед включением передачи старый буфер микрофона отбрасывается. Игровая радиосвязь не шифруется. Номера уникальны в пределах доступной сети после обнаружения; между изолированными сетями возможны совпадения. Дальность зависит от типа модемов и их настроек. Для связи компьютеры и их чанки должны быть загружены.

Проверено в CraftOS-PC с моделируемыми модемами, микрофонами и динамиками: выдача номера, разрешение конфликта, звонок, гудки, входящий при закрытом окне, принятие, включение Talk, передача DFPWM и отключение. Реальное качество звука в Minecraft требует проверки на сервере.

## Ретранслятор What'sJuz

Для связи двух телефонов за пределами прямой дальности поставьте между ними один или несколько компьютеров с беспроводными модемами. На каждом промежуточном компьютере в обычном CraftOS выполните:

    wget run https://raw.githubusercontent.com/gosuparenek/juzeppe-repo/main/downloads/whatsjuz-relay.lua

ОС на ретрансляторе не требуется. Программа сама выбирает беспроводной модем, принимает и пересылает только пакеты What'sJuz 1.0.0, включая обнаружение номеров, звонки и звук. Компьютеры телефона и ретрансляторов должны быть включены, а их чанки загружены. Расстояние между соседними узлами должно укладываться в дальность их модемов. До восьми ретрансляций на пакет; ограниченный кеш и метки пересылки подавляют дубликаты и циклы. Для постоянной работы можно сохранить скрипт под именем relay.lua и запускать его из startup.lua. Используйте отдельный компьютер для ретранслятора.

Проверено в CraftOS-PC: два телефона без прямой связи, два промежуточных ретранслятора и дополнительная петля; обнаружение, вызов, гудки, принятие, аудио и завершение звонка. Настоящая радиосвязь в Minecraft требует проверки на сервере.

### Проводная телефония (JuzeppeOS 0.9.1)

Подключите Wired Modem непосредственно к каждому компьютеру и соедините их Networking Cable. What'sJuz автоматически подключается к проводным и беспроводным модемам одновременно. Динамик и микрофон подключаются локально к каждому компьютеру, независимо от типа связи. Кабель не ограничен радиусом беспроводной связи, но его трасса и компьютеры должны находиться в загруженных чанках. Ретранслятор по кабелю не нужен. Обновите ОС на обоих телефонах; пакет What'sJuz 1.0.0 переустанавливать не требуется.
